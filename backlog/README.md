# Backlog — Cosas por hacer

Trabajo planeado, propuestas y mejoras que **aún no** están hechas. Cada ítem con
suficiente contexto para retomarlo sin re-investigar. Un ítem = un archivo en esta carpeta.

> Patrón completo: [conventions/backlog-pattern](https://github.com/csdev19/general-knowledge/blob/main/conventions/backlog-pattern.md)

**Leyenda de estado:** 🟡 En progreso (pausado) · 🟢 Listo para validar · 🔵 Propuesto · ⚪ Idea

## Cómo agregar un ítem

1. Crea `backlog/<slug>.md` con el contexto suficiente para retomarlo.
2. Agrégalo a la tabla de arriba con su estado, área y esfuerzo.
3. Al shippear, mueve el detalle a la doc de la feature y actualiza el estado.

Plantilla mínima para un ítem:

```markdown
# <Título>

**Estado:** 🔵 Propuesto · **Área:** <área> · **Esfuerzo:** <bajo/medio/alto>

## Problema / oportunidad
<qué duele o qué se gana>

## Propuesta
<enfoque, alternativas, decisión>

## Notas para retomar
<links, archivos afectados, lo aprendido>
```
